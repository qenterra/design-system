# Управление ассетами Nyx

Nyx — единственное сохранённое семейство бренд-ассетов в Design System. Новые логотипы QenTerra разрабатываются отдельно и пока не являются каноном этого репозитория. Интерфейсы наследуют основы из [`../MASTER_RU.md`](../MASTER_RU.md); графика Nyx не заменяет семантические UI-токены.

## Порядок чтения

1. [`NYX_RU.md`](NYX_RU.md) — до создания, правки, анимации или размещения Nyx.
2. [`ASSET_CATALOG_RU.md`](ASSET_CATALOG_RU.md) — для выбора существующей категории.
3. [`../../assets/brand/manifest.json`](../../assets/brand/manifest.json) — точные пути, хеши, размеры, форматы и LFS-статус.
4. [`../../templates/brand/`](../../templates/brand/) — брифы и выпускные проверки.

Английский референс: [`MASTER.md`](MASTER.md).

## Источники истины

| Область | Канонический источник |
| --- | --- |
| Интерфейсные основы | `tokens/`, `docs/MASTER_RU.md` |
| Иллюстрации Nyx | `assets/brand/nyx/` |
| Идентичность и происхождение файлов | `assets/brand/manifest.json` |
| Правила Nyx | `docs/brand/NYX_RU.md` |
| Повторяемые брифы | `templates/brand/` |
| Автоматические проверки | `scripts/brand/` |

## Жизненный цикл ассета

1. Сначала найти подходящий файл в текущем каталоге.
2. Зафиксировать функцию, размещение, состояния, ограничения и критерии приёмки.
3. Работать только в уникальной системной временной папке; оригинал хранить до приёмки.
4. Перед большой пачкой проверить репрезентативный пилот, если весь batch явно не утверждён.
5. Осмотреть оригинальный и фактический размеры на светлом и тёмном фоне.
6. Установить только утверждённые финальные файлы в `assets/brand/nyx/`.
7. Обновить `manifest.json`; каждый PNG остаётся объектом Git LFS.
8. Запустить профильные Nyx-проверки, проверку манифеста и полный gate репозитория.

Изменение идентичности, палитры, формата, категории, пути или именования — нормативное. Удаление, переименование или визуальная замена ломает контракт и требует явного утверждения, версии, changelog и migration guidance.

Сырые генерации, эксперименты с промптами, резервные копии, промежуточные изображения, контакт-листы и QA-отчёты живут во временной папке. Временный browser ассетов также пишет только вне репозитория.
