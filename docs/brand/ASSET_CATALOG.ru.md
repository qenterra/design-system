## Правило выбора

Сначала искать по функции:

1. Нужна подпись бренда — выбрать logo/banner по контрасту поверхности, масштабу и формату доставки.
2. Нужна реакция — сначала portraits; Telegram-стикер использовать, только когда уместен профиль с белой обводкой.
3. Нужно действие, направление или пропс — full-body.
4. Нужна зона под контент — compositions по названию размещения или свободного поля.
5. Нужен графический акцент — decorative, если идентичность читается и не ломается иерархия.
6. Нужен фон или pet animation — отдельный delivery profile; стикер или cutout не переиспользуется без брифа.

## Добавление и замена

- Сохранять имя категории, формат, размеры, alpha/opacity и профиль обводки.
- Новая роль получает новое семантическое имя. Существующее имя заменяется только при намеренном supersede этой же роли.
- Резервная копия целевых замен живёт вне репозитория до успешной проверки.
- Для одноразовой миграции манифест строится командой:

```bash
python3 scripts/brand/validate_brand_assets.py \
  --source "/path/to/verified-source-tree" \
  --write-manifest
```

Обычное будущее добавление использует поддерживаемый generator workflow, после чего запускаются:

```bash
python3 scripts/brand/validate_brand_assets.py --check-git-lfs
python3 scripts/verify.py
```

Исходное дерево одноразовой миграции остаётся provenance, а не вторым постоянным источником истины.
