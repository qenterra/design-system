## Выбор

1. Для реакции сначала искать portraits, затем Telegram-стикеры, если уместна профильная обводка.
2. Для направления, действия или props — full-body.
3. Для зоны контента и framing — compositions по размещению.
4. Для графической обработки — decorative, только если сохраняется иерархия.
5. Для фона или pet-анимации — отдельный delivery profile.

Новая роль получает семантическое имя. Существующий путь заменяется только при намеренном supersede той же роли. Временная резервная копия хранится вне репозитория до успешной проверки; затем обновляются манифест и полный gate.
