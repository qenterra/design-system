# Экспорты для Figma

`generated/figma/` — детерминированный мост из канонических источников Design System в автоматизацию дизайн-инструмента. Это не второй источник истины и не доказательство публикации Figma library.

## Файлы

- `variables.json`: коллекции Foundation и Semantic с режимами Default, Light и Dark.
- `styles.json`: семантические текстовые стили из ролей типографики.
- `components.json`: имена компонентов, состояния, stories и accessibility contracts.
- `icons.json`: семантические ID иконок, категории, значения, viewBox и SVG fragments.

Импортёр сохраняет имена и modes, явно сопоставляет типы color/float и сообщает о неподдерживаемых полях вместо тихой потери. Сначала импортируйте в scratch-файл, сравните количество и имена, затем обновляйте поддерживаемую Figma library только после отдельного согласования.

Сгенерированные экспорты не редактируются. Меняйте токены или registry, запускайте `python3 scripts/generate.py write`, просматривайте JSON diff и проверяйте детерминированность.
