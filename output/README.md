# Output

Generated and evidence artifacts for the initial design-system release.

- `audit-brief.md` — current-state cross-product UX/UI audit.
- `comparison-matrix.json` — machine-readable comparative assessment.
- `reports/` — deterministic build, browser, and Obsidian validation evidence.
- `screenshots/` — rendered reference-site evidence.

Output may be regenerated, but audit evidence must retain its source snapshot and verification limits.
