# QenTerraDesignTokens

Private Swift Package Manager adapter for QenTerra Design System tokens,
semantic icons, and reusable SwiftUI surfaces. The canonical sources remain in
the private `qenterra/design-system` repository; the dedicated
`qenterra/design-system-swift` repository contains the filtered package tree.

## Versioned remote dependency

Use the private distribution repository from an authorized consumer:

```swift
.package(
    url: "https://github.com/qenterra/design-system-swift.git",
    from: "1.12.0"
)
```

Select the `QenTerraDesignTokens` product and import it in application code.
Private GitHub access must be configured by the developer or CI environment;
CI credentials should be read-only and scoped to this repository. Never place
credentials in `Package.swift`, source control, or package mirrors.

## Local development

In Xcode, add the local package at `packages/swift`, then import it:

```swift
import QenTerraDesignTokens

let spacing = QDS.Space.value4
let duration = QDS.MotionSeconds.disclosure
```

## Public API map

- `QDS` exposes generated scales, semantic colors, typography, motion, and
  component metrics.
- `QDSIcon` exposes reviewed semantic icon identifiers.
- `QDSPrimaryButtonStyle` and `QDSGroupContainer` provide small SwiftUI recipes.
- `QDSInteractiveRowSurface` and `QDSInteractiveRowState` preserve the shared
  selection, focus, disabled, and increased-contrast priority.

The package supports macOS 13+ and iOS 16+ and has no external dependencies.

## Source ownership and verification

`QDSGeneratedTokens.swift` is generated by `scripts/build.py`. Change `tokens/*.json`, never the generated package source.

From the canonical repository, run:

```sh
swift test --package-path packages/swift
swift run --package-path packages/swift QDSContractCheck
python3 scripts/package_release.py validate
```

`swift test` requires a complete Xcode test runtime. The repository verification
gate always builds the package and runs `QDSContractCheck`; it does not pretend
that unavailable native test or product-runtime coverage passed.
