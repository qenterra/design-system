# QenTerraDesignTokens

Local Swift Package Manager adapter for QenTerra Design System tokens.

In Xcode, add the local package at `packages/swift`, then import it:

```swift
import QenTerraDesignTokens

let spacing = QDS.Space.value4
let duration = QDS.MotionSeconds.disclosure
```

`QDSGeneratedTokens.swift` is generated by `scripts/build.py`. Change `tokens/*.json`, never the generated package source.

`swift test` runs the package tests with a complete Xcode toolchain. The repository verification gate builds the package and runs `QDSContractCheck`, so Command Line Tools installations without a usable test runtime still verify the public API without pretending the unavailable test runner passed.
