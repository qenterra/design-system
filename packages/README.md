# QenTerra packages

Public installable outputs of Design System. Canonical sources, private assets, agent instructions, and governance remain in the private Design System repository.

## npm

```sh
npm install @qenterra/design-tokens
```

## Swift Package Manager

Add `https://github.com/qenterra/packages` and select either product:

- `QenTerraDesignTokens` for typed foundations and SwiftUI token adapters;
- `QenTerraComponents` for the existing primary-button, group-container, and interactive-row primitives.

Every released file is declared in `release-manifest.json`. Apache-2.0 applies; preserve `NOTICE` when redistributing the work.
