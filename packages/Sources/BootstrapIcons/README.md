# Bootstrap Icons

This directory preserves 2078 exact, unmodified SVG sources from [Bootstrap Icons](https://icons.getbootstrap.com/) at upstream commit [`6945b7006285d444cc17ff2e22c7691719229526`](https://github.com/twbs/icons/commit/6945b7006285d444cc17ff2e22c7691719229526). Available styles: `default`.

The upstream MIT license is reproduced in `LICENSE`. File-level provenance, byte sizes, and SHA-256 digests are recorded in `manifest.json`.

## Usage boundary

- Search this catalog before drawing a new icon.
- Use one external icon family consistently within a project.
- Do not edit these upstream originals. Store an approved derivative separately and document its provenance.
- These files are reference assets, not an npm or SwiftPM target.
