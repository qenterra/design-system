# UX copy review: <surface>

## Terminology

List canonical terms and prohibited synonyms.

## Actions

Confirm every action starts with a verb, names the result, and uses an ellipsis only when more input is required.

## States and outcomes

Confirm copy distinguishes requested outcome, fallback, partial result, cached data, and persisted data.

## Errors

For each error: what happened, what remains safe, and the next action.

## Localization

Check String Catalog/i18n source, plurals, placeholders, dates, numbers, byte sizes, lists, 30% expansion, and long unbreakable values.

## Accessibility

Check icon-only labels, control names, progress values, status announcements, and shortcut notation.
